# WspółKoszyk — polityka prywatności

Ten repozytorium hostuje politykę prywatności aplikacji **WspółKoszyk**.

## Adres do Google Play

Po włączeniu GitHub Pages użyj URL:

`https://iwo2003.github.io/Wsp-Koszyk/`

## Jak włączyć GitHub Pages

1. Settings → Pages  
2. Branch: `main` → folder `/ (root)`  
3. Save  

Poczekaj 1–2 minuty, aż strona będzie dostępna.
